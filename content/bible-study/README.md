# 성경 연구 원고 관리

`books.ko.md`는 앱에 표시할 66권 전체의 한국어 연구 안내 원고입니다. 앱 코드에 설명을 직접 쓰지 않고, 이 원고를 먼저 고친 뒤 빌드합니다.

## 편집 원칙

1. 성경 한 권마다 `읽기 방향`, `큰 흐름`, `설교 준비 질문`, `해석 주의`를 모두 작성합니다.
2. 확인하지 않은 연대, 저자, 장소, 이동 경로를 사실처럼 단정하지 않습니다.
3. `status`와 `review`를 사실대로 유지합니다. 전문 검수를 받기 전에는 `editorial-draft`, `pending`입니다.
4. 구절별 자료는 Aquifer Open Study Notes와 공개 성경 본문을 앱에서 별도로 연결합니다. 이 파일은 원문을 복제하는 곳이 아닙니다.
5. 한 권만 고친 뒤 전체가 완성된 것처럼 표시하지 않습니다. 빌드 검사는 66권의 필수 항목과 중복·누락을 모두 검사합니다.

## 빌드

```powershell
npm run build:pastoral-books
```

결과는 `public/data/pastoral-books.json`에 생성됩니다. `--check` 검사는 생성 결과가 원고와 같은지 확인하며 파일을 수정하지 않습니다.
